macOS · Mail.app · MCP · MIT

Apple Mail, for the agent on this Mac.

Selo is a local MCP server. It uses the accounts already in the Mail app. It reads, replies, replies to all, forwards, attaches files, sends, downloads attachments, deletes to Trash, unsubscribes from a list, and points at signs a message looks suspicious.

Sending, replying, forwarding, deleting, and unsubscribing really happen. Delete goes to Mail's Trash. The suspicion check is a local heuristic, not an antivirus. Selo stores no password and has no server of its own.
